# Contributing

Thanks for helping. Small, focused PRs are welcome.

1. Open or comment on an issue first for anything beyond a small fix.
2. Fork, create a branch, make one logical change.
3. Run `npm install`, `npm run typecheck`, `npm test`.
4. Open a PR that links the issue and explains why the change is useful.

Good first issues are labelled `good first issue`. Achievement thresholds are
community-documented, so please cite a source when adding or changing a tier.
Please be kind and constructive in all discussions.
